# Pdf417EncodeMode

PDF417 barcode encode mode. Mirrors https://reference.aspose.com/barcode/net/aspose.barcode.generation/pdf417encodemode/

## Allowable values

* **Pdf417EncodeMode.auto** (`"Auto"`)
* Pdf417EncodeMode.binary (`"Binary"`)
* Pdf417EncodeMode.eci (`"ECI"`)
* Pdf417EncodeMode.extended (`"Extended"`)
