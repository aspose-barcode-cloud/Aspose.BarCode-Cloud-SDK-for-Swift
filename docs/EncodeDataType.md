# EncodeDataType

Types of data that can be encoded into a barcode.

## Allowable values

* **EncodeDataType.stringData** (`"StringData"`)
* EncodeDataType.base64Bytes (`"Base64Bytes"`)
* EncodeDataType.hexBytes (`"HexBytes"`)
